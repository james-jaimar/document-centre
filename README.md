# Document Centre

Document Centre is a multi-tenant web-to-print SaaS platform — modern storefronts, configurable products, integrated production workflows, and per-branch operations.

**Production:** https://document-centre.com

## Tech stack

- Vite + React 18 + TypeScript
- Tailwind CSS + shadcn/ui
- Supabase (Postgres, Auth, Storage, Edge Functions)

## Local development

```sh
npm install
npm run dev
```

## Deployment

Deployed via Lovable. Custom domain configured in **Project Settings → Domains**.
